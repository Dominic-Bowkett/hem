# HEM Field Assessment Tool

Working notes and architecture for a tablet-first Progressive Web App that wraps the
open-source UK [Home Energy Model](https://github.com/communitiesuk/epb-home-energy-model)
engine, aimed at independent Domestic Energy Assessors ahead of the October 2029
HEM mandate.

## Documents

- **[HEM Integration Plan](hem-integration-plan.html)** &mdash; recommended architecture
  (Rust&nbsp;&rarr;&nbsp;WebAssembly engine, TypeScript wrapper, React PWA shell),
  phased delivery, risks, verification approach, and source links.

## Status

Planning phase. No code yet &mdash; this site exists to share the proposal and gather
feedback before any spike work begins.
